# Temperature Converter

A simple, responsive Temperature Converter web application.

Convert temperatures between Celsius (°C), Fahrenheit (°F), and Kelvin (K).

## Features

- Convert between all three temperature units (6 directions)
- Automatic conversion as you type
- Swap source and destination units
- Input validation (including absolute-zero checks)
- Light and dark themes with persistence

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
